# Sales Dashboard (Forecasting)

 ->Project Overview
The Sales Dashboard (Forecasting) is an interactive Power BI dashboard developed to analyze and visualize sales performance across different categories, regions, segments, payment modes, and shipping methods. The dashboard helps in understanding business trends, monitoring KPIs, and forecasting future sales for better decision-making.

This project uses historical sales data to generate meaningful insights and identify growth opportunities through visual analytics and forecasting techniques.



-> Objectives
- Analyze overall sales and profit performance
- Track monthly and yearly sales trends
- Identify top-performing categories and sub-categories
- Understand customer purchasing behavior
- Compare sales across regions and states
- Forecast future sales using historical data



-> Tools & Technologies Used
- Power BI
- SQL
- Excel



-> Dashboard Features
- Interactive and visually appealing dashboard
- Sales forecasting analysis
- KPI Cards for:
  - Total Sales
  - Total Profit
  - Quantity Sold
  - Average Delivery Days
- Sales analysis by:
  - Category
  - Sub-Category
  - Segment
  - Ship Mode
  - Payment Mode
  - State/Region
- Region-wise filtering using slicers
- Monthly and yearly trend analysis
- Map visualization for state-wise sales and profit



-> Key Insights
- Consumer segment contributes the highest share of sales.
- Office Supplies category generates maximum revenue.
- Standard Class is the most commonly used shipping mode.
- COD and Online payment methods dominate customer transactions.
- Sales show significant growth during the end months of the year.
- Forecasting helps predict future business performance and trends.



-> Forecasting Analysis
The forecasting feature in Power BI is used to predict future sales trends based on historical sales patterns. This helps businesses:
- Estimate future revenue
- Identify seasonal trends
- Improve planning and inventory management
- Make data-driven business decisions




->Files Included
- `SalesDashboard.pbix` – Power BI dashboard file
- `Dataset.xlsx` – Dataset used for analysis
- `README.md` – Project documentation



-> How to Use
1. Download the Power BI `.pbix` file.
2. Open the file in Power BI Desktop.
3. Refresh the dataset if required.
4. Use filters and slicers to interact with the dashboard.
5. Explore visual insights and forecasting results.



-> Conclusion
This project demonstrates how Power BI can be used to transform raw sales data into meaningful business insights through interactive visualizations and forecasting techniques. The dashboard enables efficient monitoring of business performance and supports strategic decision-making.
